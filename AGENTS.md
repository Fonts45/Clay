# Instruções permanentes do projeto Clay

## Identidade visual aprovada pelo usuário

Em 30/10/2026, o usuário pediu explicitamente que a identidade visual atual seja preservada e aplicada consistentemente em TODAS as alterações futuras. Não redesenhe nem substitua o estilo por iniciativa própria. Só altere a identidade quando o usuário solicitar; uma mudança pontual não autoriza redesenhar outras áreas.

Leia `docs/IDENTIDADE-VISUAL.md` antes de criar ou alterar interfaces. Reutilize os componentes e estilos atuais, consultando seus valores efetivos nos arquivos CSS. Não introduza outra paleta, tipografia ou sistema de bordas. Não reative elementos que o usuário removeu. Instruções mais recentes do usuário têm prioridade.
